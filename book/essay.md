# A Library

This book contains all {books} books on my shelves, as of {date}. I generally like to just alphabetize them, so that is how they stand here as well. 

Every spine is drawn at {scale} of its real size, from two numbers: how tall the book is, and how thick. I found the height of {height_known}. The other {height_guessed} heights are guesses (I will be measuring them as time allows). Thickness is harder to find. Only {thick_known} came with one. For {thick_from_pages} more, a short rule worked it out from the page count. The other {thick_guessed} are guesses, and a rule made those too.

After that, I still didn’t draw any of these spines. Nor did I work at all with the traditional software tools for page layout — Illustrator, InDesign, Affinity, Inkscape. The catalogue predominantly lives in a database and some template files. A script turns it into a website, library.wjerk.shop, and the same data feeds a different folder of html and css and python files and becomes this book. Another script lines up the spines, starts a new stretch of shelf when one fills, and cuts a title back to its last whole word when it won’t fit. I wrote the rules to my vision, and the rules make the pages. When a page looks wrong, I change the rules to improve it.

A design system is a set of written-down decisions: these colors, this type, this space usage. I have been trying to build a much clearer personal design system to not have to make the same decision twice. This way a script, a student, or even an AI can make a decision the way I would. It holds my taste, so I can spend my attention (hopefully) more wisely. And more rapidly get to the "normal" way that I would start a design problem.

The tools are open. Thirteen typefaces set the spines, all under the SIL Open Font License, which lets anyone use, change and share them. The software that set them is open source. The text is Creative Commons. The catalogue is a public file anyone can download.

I have read a lot. A lot about technology, design, and how we consider the ethics of design out in the world. I also like to make things. Why not make something about all the books that I have read (or at least intend to read!).

The design of this is a minor homage to "I Seem to Be a Verb" by Buckminster Fuller and Jerome Agel.
