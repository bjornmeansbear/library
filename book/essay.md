# A Library

These are the {books} books on the shelves of my office at MICA, on {date}. I file them by title, A to Z, so that is how they stand here. Every spine is drawn at {scale} of its real size. {sizes}

I didn’t draw any of it by hand. The catalogue lives in a database. A script turns it into a website, library.wjerk.shop, and the same data feeds this book. Another script lines up the spines, starts a new stretch of shelf when one fills, and cuts a title back to its last whole word when it won’t fit. I wrote the rules, and the rules made the pages. When a page looked wrong, I changed the rule that made it.

A design system is a set of written-down decisions: these colours, this type, this much space. I keep one so I don’t have to make the same decision twice, and so a script, a student or an AI can make a decision the way I would. It holds my taste, so I can spend my attention on the next decision instead of the last one.

The tools are open. Thirteen typefaces set the spines, all under the SIL Open Font License, which lets anyone use, change and share them. The software that set them is open source. The text is Creative Commons. The catalogue is a public file anyone can download.

Some of these books are about the commons: things nobody owns and everybody can use. Enzo Mari’s *Autoprogettazione* gave away plans for furniture anyone could build with a saw and nails. Christopher Alexander’s *A Pattern Language* numbered 253 design solutions and handed them over. *The Whole Earth Catalog* called itself access to tools. I think design is heading back that way, toward a new design commons, where designers share their methods, files and systems. This book is a small one.
